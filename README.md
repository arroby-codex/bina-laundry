# Bina Laundry 🧺

Aplikasi atau sistem manajemen laundry untuk mempermudah pengelolaan transaksi, pencatatan pelanggan, dan status pengerjaan cucian.

## 🚀 Fitur Utama
* **Manajemen Pelanggan:** Menyimpan data kontak dan riwayat cucian pelanggan.
* **Pencatatan Transaksi:** Mengelola jenis layanan (kiloan, satuan, dry clean) beserta status pembayarannya.
* **Tracking Status:** Memantau proses cucian (baru masuk, proses cuci, setrika, siap diambil).
